# Netflix Content Analytics

## Project Overview
Analyzed Netflix Movies and TV Shows dataset to identify content distribution, category patterns, country-wise trends, and release insights.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Charts
- Data Cleaning

## Key Highlights
- Analyzed 8,806 Netflix titles, including 6,130 movies and 2,676 TV shows, to identify content distribution, category patterns, and release trends.
- Cleaned and prepared the dataset by handling missing values, standardizing inconsistent fields, and correcting year/month information.
- Created 10+ PivotTable analyses covering content type, country, ratings, genres, directors, release year, duration, and trends to derive meaningful content insights.

## Project Outcome
Developed analytical insights into Netflix's content library through structured data analysis and visualization.
